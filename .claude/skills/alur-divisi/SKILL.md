# Alur kerja divisi

Aku membantu kamu mendapat hasil melalui langkah yang dapat diperiksa.
Fondasi sekali: brief/fakta/sumber yang diizinkan, arah dan aturan selera.
Tiap tugas: konsep → pilihan owner → produksi → pemeriksa terpisah → revisi
maksimal tiga putaran → keputusan owner. Hasil gagal tetap gagal.

- Sosmed: Penggali → Kurator → pilihan sudut → Penulis → Satpam → owner;
  visual melalui sistem-desain-brand/carousel, video melalui Sutradara:
  video-explainer (menjelaskan topik bersumber), video-affiliate (jualan dari
  link produk; brief disetujui owner sebelum biaya fal), video-remotion (lainnya).
- Marketing: tujuan/batas → konsep satu pesan → pilihan → materi Sosmed →
  pemeriksa-iklan → rencana A/B → angka asli → usulan pause/ganti; naik budget
  selalu izin owner. Kit tidak otomatis berwenang di akun iklan.
- Katalog: fakta → sudut Marketing → copy/foto Sosmed → cek-listing dan
  pemeriksaan fakta → owner upload. Gambar tidak boleh mengubah produk.
- Accounting: sumber/periode/jam → alat hitung → pasti/perkiraan/belum kecatat
  dan kurs jelas → pemeriksa-angka → owner → notif hanya jika tujuan/izin ada.
- Software/Web: salinan pratinjau → tes/foto HP/laptop → pemeriksa-kode →
  versi beku dan rencana balik → owner menerbitkan → cek publik.
- Support: lingkup izin owner → kabar singkat → panduan → pemeriksa-support
  → jawaban/eskalasi → tindak lanjut. Default draf; jangan mengirim pada latihan.

Revisi: minta bagian, masalah, batas dan alasan. Simpan yang disepakati ke
brand/aturan-<divisi>.md dengan sebelum/sesudah, konteks, pengecualian dan
sumber keputusan. Baca sebelum tugas berikutnya. Revisi selera tidak mengubah
fakta. Penilaian menyebut cakupan nyata: storyboard bukan video, rencana bukan
tayang, pengiriman bukan pembacaan HP. Alat kurang → dilewati, bukan berhasil.
