# late30 arah 2: Berita (kartu kapital tebal)

Rasa: kartu berita game. Kotak judul solid tembus tepi layar, huruf kapital tebal, slab warna penuh bertumpuk.
- Dasar gelap, kotak utama pink (teks krem, ukuran besar), slab kuning/krem untuk teks gelap. Satu kata penting di kotak gelap berhuruf kuning.
- Font: Liberation Sans Bold (kapital via CSS text-transform) + DejaVu Sans Mono (wordmark tag, label). Ukuran 80 / 40 / 32 / 22.
- Tipe slide: cover = lockup besar + kotak pink + garis kuning; banding = kotak judul krem + dua slab beda tinggi; penutup = kotak pink + lockup + garis kuning.
- Jangkar: judul kapital 80 px. Motif: garis kuning/slab penuh (jaga maksimal dua slide per carousel).
- Tidak ada gambar; kartu berita pihak lain tidak disalin. Teks tetap huruf campur di HTML, kapital hanya tampilan.
- Berkas: carousel/karya/late30-arah-2/index.html, render hasil/late30-arah-2/.
