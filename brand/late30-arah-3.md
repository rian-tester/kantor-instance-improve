# late30 arah 3: Terminal (blok piksel)

Rasa: jendela terminal dengan huruf mono setara blok piksel wordmark. Sudut persegi, bayangan keras tanpa blur, kisi, kursor blok kuning.
- Dasar gelap + kisi 54 px, bilah judul jendela (tiga kotak warna, wordmark, enam blok = nomor slide), kotak berbingkai krem dengan bayangan pink/kuning.
- Font: satu keluarga, DejaVu Sans Mono Bold/Regular. Ukuran 88 / 40 / 32 / 22.
- Tipe slide: cover = lockup + kotak judul berkursor; banding = dua baris berbatang urutan; penutup = kotak judul + garis + lockup.
- Jangkar: judul mono 88 px. Motif: bayangan keras/kursor (maksimal dua slide).
- Catatan: batang di banding hanya urutan, bukan angka; Kritikus/Satpam perlu menilai apakah panjangnya menyiratkan angka.
- Berkas: carousel/karya/late30-arah-3/index.html, render hasil/late30-arah-3/.
